Инструкция по работе с ботом

Яро ведёт диалог с вашими клиентами 24/7, напоминает о себе и сигнализирует когда клиент готов к сделке

Начало работы
1
Найдите бота в Telegram
Откройте поиск и найдите @yaro_rieltor_bot — нажмите Start
2
Дождитесь одобрения
Администратор активирует ваш аккаунт. Обычно занимает несколько минут
3
Добавьте первого клиента
Введите команду — получите ссылку — отправьте клиенту. Яро начнёт общение
Добавление клиентов

Покупатель

Используйте команду /add с параметрами: имя, бюджет, район, тип жилья

Пример
/add Иван 5млн Советский 3к
/add Мария 8млн центр 2к новостройка
/add Алексей 12млн Ленинский дом

Продавец

Используйте команду /sell с параметрами: имя, цена, адрес, площадь, тип

Пример
/sell Петров 7млн Ленина45 65м 3к
/sell Смирнова 4.5млн Мира12 42м 1к

После команды бот пришлёт ссылку-приглашение. Отправьте её клиенту — он перейдёт и начнёт общаться с Яро.

Управление клиентами
/clients
Список всех активных клиентов с последней активностью
/chat Имя
Посмотреть историю диалога Яро с конкретным клиентом
/note Имя текст
Добавить заметку к клиенту (договорились о встрече, особые пожелания)
/done Имя
Закрыть сделку — перевести клиента в архив
/archive
Список завершённых клиентов
/help
Полная справка по всем командам
